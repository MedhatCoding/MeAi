# أمان التطبيق وإعدادات الحماية

يشرح هذا الملف إعدادات الحماية المتاحة في واجهة Next.js وكيفية تفعيلها بأمان.

## بوابة المصادقة لواجهات الذكاء الاصطناعي (جديد)

مسارات المحادثة والبحث والوكيل وتوليد الصور تستهلك تكلفة حقيقية عبر مفاتيح المزوّد. تمت إضافة بوابة مصادقة اختيارية تحمي هذه المسارات:

- `/api/chat`
- `/api/search`
- `/api/research`
- `/api/images/generate`
- `/api/agent/plan`
- `/api/agent/code`
- `/api/agent/artifact`
- `/api/agent/execute`

### طريقة التفعيل

البوابة تعمل تلقائيًا بمجرد ضبط `MEAI_AGENT_ALLOWED_EMAILS` على الاستضافة (نفس القائمة المستخدمة لتعديلات GitHub)، ويستثنيها ضبط `MEAI_REQUIRE_AUTH=false`. لتفعيلها يدويًا حتى بدون قائمة بريدية اضبط `MEAI_REQUIRE_AUTH=true`.

عند تفعيل البوابة، يجب تسجيل الدخول بحساب مؤكد ضمن القائمة المسموحة. الواجهة ترسل تلقائيًا رمز الجلسة المحفوظ في `sessionStorage` مع الطلبات المحمية عبر `app/auth-fetch.tsx`.

### ترتيب خطوات التفعيل الآمن

1. تأكد أن `NEXT_PUBLIC_SUPABASE_URL` و`NEXT_PUBLIC_SUPABASE_ANON_KEY` و`MEAI_AGENT_ALLOWED_EMAILS` مضبوطة.
2. سجّل الدخول من صفحة الإعدادات وتأكد أن البريد مؤكد.
3. فعّل البوابة بضبط `MEAI_REQUIRE_AUTH=true` أو بضبط القائمة المسموحة.
4. اختبر المحادثة والبحث والوكيل بعد تسجيل الدخول. إذا ظهرت رسالة 403 فالجلسة منتهية؛ سجّل الدخول مرة أخرى.

## حماية التعديل الآلي للملفات

- تعديل ملفات GitHub معطل افتراضيًا (`MEAI_AGENT_EDIT_ENABLED`).
- الوكيل لا يستطيع تعديل أي ملف داخل `app/api/` (كود الخادم) أو ملفات الأمان والإعدادات، حتى مع تفعيل التعديل. مسموح فقط ملفات واجهة `app/` (باستثناء `app/api`) و`components/` و`lib/`.
- النشر من مساحة العمل يظل محصورًا في مجلد `.medhat-workspace/`.

## حدود معروفة

- حد الطلبات (rate limit) يعمل داخل كل نسخة من الخادم فقط، وذاكرته محدودة بسقف 5000 عنوان. للاستضافة متعددة النسخ استخدم حد طلبات مشتركًا على مستوى الـ edge.
- لا تضع أي مفاتيح API في ملفات المستودع؛ استخدم أسرار منصة الاستضافة أو Streamlit Secrets فقط.
